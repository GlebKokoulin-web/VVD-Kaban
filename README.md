
# VVD Kaban — Сварка и изготовление отвалов для спецтехники

Лендинг-сайт для компании **VVD Kaban** — профессиональное изготовление отвалов для Нивы, УАЗа, Караката и другой спецтехники. Производство в г. Киров, доставка по всей России.

## 📋 О проекте

Одностраничный сайт (лендинг) с информацией об услугах компании, галереей выполненных работ и контактной информацией. Сайт оптимизирован для SEO и включает все необходимые мета-теги для поисковых систем и социальных сетей.

### Основные разделы

| Раздел | Описание |
|--------|----------|
| **Hero** | Главный экран с заголовком и призывом к действию |
| **Services** | Перечень услуг компании |
| **Benefits** | Преимущества работы с компанией |
| **Gallery** | Галерея выполненных работ с лайтбоксом |
| **Contact** | Контактная информация (MAX, Avito, адрес) |
| **Footer** | Подвал с контактами и правовой информацией |

## 🛠 Стек технологий

- **React 19** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS v4** — CSS-фреймворк
- **shadcn/ui** — UI-компоненты
- **Lucide React** — иконки
- **React Router DOM** — роутинг
- **Sonner** — toast-уведомления

## 🚀 Быстрый старт

### Требования

- **Node.js** 18+
- **npm** / **yarn** / **pnpm**

### Установка

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd <project-directory>

# 2. Установить зависимости
npm install

# 3. Запустить локальный сервер разработки
npm run dev
```

После запуска откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
# Сборка production-версии
npm run build

# Локальный просмотр production-сборки
npm run preview
```

## 📝 Скрипты

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск сервера разработки с HMR |
| `npm run build` | Production-сборка (output в `dist/`) |
| `npm run preview` | Локальный просмотр production-сборки |

## 🎨 Дизайн

Сайт использует цветовую схему с акцентным оранжевым цветом (`#ea580c` / `orange-600`) на тёмно-синем/чёрном основном цвете. Дизайн адаптивен и корректно отображается на мобильных устройствах, планшетах и десктопах.

### CSS-переменные

Основные переменные определены в `src/index.css`:

- `--background` — фоновый цвет
- `--foreground` — цвет текста
- `--primary` — основной цвет (тёмный)
- `--radius` — радиус скругления

## 🔧 Конфигурация

### Vite

Конфигурация в `vite.config.ts`. Используется React плагин и настроен алиас `@` для импорта из `src/`.

### Tailwind CSS

Используется **Tailwind CSS v4** с JIT-режимом. Конфигурация в `tailwind.config.ts`.
